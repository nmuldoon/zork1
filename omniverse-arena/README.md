# Omniverse Arena

An OASIS-inspired, multi-genre battle royale prototype.

- `game.html`: playable 3D prototype (Three.js). Built to run as a claude.ai artifact, where it gets live multiplayer (room), saving clips and photos (downloads) and the owner-only Architect kit (user). Opened as a plain file it runs in solo mode.
- `design-bible.html`: the game design document.

## Controls
WASD move · mouse look · click fire/use · Space jump · Shift sprint · E interact · 1–0 hotbar · I backpack · V ride vehicle · G emote · T chat · Tab leaderboard · R record clip · P photo · ✎ (top-left) Character Creator
